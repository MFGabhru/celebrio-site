Self-hosted webfonts (latin subset), from Google Fonts / Fontsource. All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling and self-hosting.

Site UI:
- `inter-tight-var.woff2` — Inter Tight (variable 100–900)

Card art only:
- `fraunces-var.woff2`, `fraunces-var-italic.woff2` — Fraunces (variable 100–900)
- `playfair-var.woff2`, `playfair-var-italic.woff2` — Playfair Display (variable 400–900)
- `cormorant-var.woff2`, `cormorant-var-italic.woff2` — Cormorant Garamond (variable 300–700)
- `pinyon-script.woff2` — Pinyon Script (400)
- `caveat-var.woff2` — Caveat (variable 400–700)
- `fredoka-var.woff2` — Fredoka (variable 300–700)
- `josefin-sans-var.woff2` — Josefin Sans (variable 100–700)
- `space-mono-400.woff2`, `space-mono-700.woff2` — Space Mono (400, 700)

The SVG download embeds the fonts a card uses, which the OFL permits when the fonts travel with the document.
